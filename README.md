One funny line pitching the worst pizza topping imaginable: wet cardboard. It opens like a new-product announcement, then the punchline reveals the topping tastes exactly like the box the pizza came in — because it is the box the pizza came in. The program writes the 111-character pitch to `/output/entry.txt`, checks it against the competition gate (1–200 characters, a single line), and reads the file back to verify it.

## Run it

```sh
python3 main.py
```
