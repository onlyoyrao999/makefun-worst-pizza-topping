An entry for make.fun's "The Worst Pizza Topping" bounty: a single joke line that tries to sell wet cardboard as a pizza topping, with the twist that it tastes exactly like the box it arrived in — because it *is* the box. `main.py` drops the 111-character line into `/output/entry.txt`, measures it against the contest limits first (no more than 200 characters, one line, not blank), then reads the file back to confirm what landed on disk matches the line exactly.

## Run it

```sh
python3 main.py
```

Pass `--output <path>` to write somewhere else, or set `ENTRY_OUTPUT`; add `--print` to see the line on stdout too.
